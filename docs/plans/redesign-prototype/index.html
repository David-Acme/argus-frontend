Argus: redesign prototype

Static prototype of the redesign in redesign-spec.md. Calm, content-first and near-monochrome, in the spirit of Threads. Every screen is built from the same twenty components, which the spec lists, and the CSS classes here map to them.

Principios

1. Lo importante primeroEach screen opens on one sentence of status and one obvious action.
2. Calma, no alarmaRed appears only for real alerts. Everything else is ink on paper.
3. Se aprende usandoNo tutorials. Empty states teach and offer the first step.
4. Pocas piezasAbout 20 components with few variants, reused on every screen.
5. Natural en cada plataformaNative sheets, alerts, haptics and press feedback; dialogs on desktop.
6. Honesto con el estadoLoading, offline and failure never look like "nothing here".
7. Para todos48 dp targets, AA contrast, text up to 200%, dark mode treated as carefully as light.

Tokens

One neutral ramp, one accent (arena), three status colours. Six text sizes, two weights. Spacing 4·8·12·16·24·32·48. Radii 8·12·20·full. Elevation only on what floats: sheets, dialogs, menus and toasts.

Pantallas principales (teléfono, claro)

360 × 760 dp. Bottom bar: Inicio · Seguridad · Argus · Agenda · Tú. Argus sits in the centre, where Threads puts compose: the assistant is how people create things.

Detalles, hojas, diálogos y estados

The bottom sheet (snap points, grabber, the field kept above the keyboard, Return = Guardar), the native alert, the skeleton that matches the final layout, the empty state with one action, offline and stale data shown honestly, undo instead of "¿Seguro?", and text at 130%.

Modo oscuro

The same screens with the dark tokens. No pure black. Fills sit above surfaces so checkboxes and empty cells stay visible. The status colours are lighter so they keep their contrast.

Escritorio (1280 × 800, Tauri / web)

Same tokens and components. A sidebar with labels replaces the bottom bar at ≥ 1024 px. The feed column is capped at 600 px, with a quiet aside on the right. A form opens as a centred dialog (Esc closes it, ⌘/Ctrl+Enter saves), never as a stretched phone sheet. Hover states appear only where there is a pointer.
